# Virtual Voice 1.8.0 Windows acceptance

Date: 2026-11-23 (UTC+8)

Branch: `codex/cursor-audio-scene-fixes`

Base: Cursor TTS branch, commit `e3ae9088507c43e1be0d761385925c93cc3a8ae2` (includes PRs 1, 2 and 3).

## Changes

- Audio overwrite decodes first, writes and syncs a temporary file in the recording directory, and commits it with a Windows-compatible atomic replacement. Previous audio formats are removed only after the replacement succeeds. Cleanup errors are no longer silently ignored.
- Input and output device discovery use independent functional state setters. Device/scene changes no longer recreate the refresh callback or rerun configuration initialization during the 400ms save delay.
- Application version is 1.8.0 across frontend, package metadata/lockfiles, Rust manifest/lockfile, Tauri config and both README references. The existing local acceptance installer was 1.7.0.
- Frontend Tauri API is pinned to 2.10.1 to match Rust Tauri 2.10.3. The previously resolved API 2.12.3 blocked the native package build.

## Verification

- Before fix: scene regression failed because saved `active_scene` reverted to null. Two audio failure tests failed because the original file had been deleted.
- `npm test`: 2 passed. Covers scene devices, volume, monitoring, DSP and selected scene persistence with transfer idle/running and a focus refresh; running transfer restarts with the selected preset.
- `cargo test --offline --manifest-path src-tauri/Cargo.toml`: 22 passed, 0 failed on Windows. Includes invalid-base64 preservation, failed destination replacement preservation, successful existing-file replacement and old-format cleanup.
- `npm run tauri build`: exited 0; production frontend compiled and both x64 MSI and NSIS installers generated.
- Native executable file version: 1.8.0.
- Windows UI smoke: launched the executable from this checkout; verified main UI, version footer, settings dialog and TTS settings content. Did not save or trim any existing recording.
- Read-only code review: approved; no actionable correctness findings.

Non-blocking existing build warnings: unused `DriverStatus::Unknown`, old Browserslist database, and bundle identifier ending in `.app` (macOS advice).
